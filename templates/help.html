Welcome to the Help Page!

How to Borrow a Book

  • To borrow a book, select a book from the available books list under Borrow section.

How to Return a Book

  • After borrowing a book, you can return it by selecting the book and specifying the return date under Return Book section.

Features:

  • View Available Books: Browse through the library's catalog of books, sorted by genre, author, and availability.
  • Borrow Books: Easily borrow books by selecting from the available titles and specifying the borrow date.
  • Return Books: When you're finished, simply return books to update their availability in the library.
  • Manage Authors: Add and view authors to ensure the library's database stays updated.
